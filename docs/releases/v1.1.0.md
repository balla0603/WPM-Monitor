# WPM Monitor v1.1.0

## 繁體中文

- 全新總覽：六張統計卡片、近七日趨勢及速度分布。
- 新增繁體中文與英文切換，並保存語言設定。
- 頂部快速控制暫停、主題及隱藏至系統匣。
- 保留打字速度與修正統計、歷史紀錄及 CSV 匯出。

新版使用獨立的統計資料路徑，舊資料不會被覆寫，但尚未自動匯入。請先結束舊版再啟動。

## English

- Redesigned overview with six metric cards, a seven-day trend chart and speed distribution.
- Added Traditional Chinese and English switching with persistent language settings.
- Quick access to pause, theme and system tray controls.
- Typing and correction metrics, history and CSV export.

This version uses a separate statistics directory. Previous data is preserved but not imported automatically. Exit the previous version before launching.

Windows 10/11 x64. Unsigned executable; Windows runtime verification is pending.
